# College Placement Data Analysis

## 📌 Project Overview
The College Placement Data Analysis project focuses on analyzing student placement data to understand the factors that influence campus placements. It helps identify patterns and insights related to students' academic performance, skills, and placement outcomes.

## 🎯 Objectives
- Analyze college placement data.
- Understand factors affecting student placements.
- Explore relationships between academic scores and placement results.
- Identify trends and patterns in placement data.
- Present useful insights to support data-driven decision-making.

## 🛠️ Technologies Used
- **Python** – Data analysis and processing
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **CSV** – Dataset storage
- **HTML** – Web page / project interface

## 📊 Dataset
The project uses CSV files containing college placement-related data. These datasets can be used to explore student details, academic performance, and placement outcomes, depending on the available columns.

## ⚙️ How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/samrudhipatil13/College_Placement_Simple.git
   ```

2. Navigate to the project folder:
   ```bash
   cd College_Placement_Simple
   ```

3. Install the required Python libraries, if needed:
   ```bash
   pip install pandas numpy
   ```

4. Run the Python application:
   ```bash
   python app.py
   ```

5. Open the HTML file in a browser if you want to view the HTML interface separately.
